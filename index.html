Detection engineering

I write detections that catch behavior, not single events. Instead of alerting on one failed login, I look for patterns: five failures from one source in five minutes, encoded PowerShell, recon commands in a burst.

# 04-encoded-powershell-detection.spl
source="...PowerShell/Operational"
| search Message="*EncodedCommand*"
    OR Message="*-enc *"
| eval DecodedPayload=substr(Message, 1, 500)
| table _time, DecodedPayload

✓ payload decoded · T1027 · T1059.001
